# Three Kingdoms Memes

Contextual meme retrieval for the 2010 television series *Three Kingdoms* on QQ Official and SnowLuma.

The plugin matches strong phrases in the current message and injects at most two relevant entries as temporary user content. It does not modify the system persona or persist injected material in conversation history. Generic words are intentionally excluded as standalone triggers to prevent false positives.

Reply guidance favors a short continuation or reaction when the other person is clearly using a meme. It preserves factual answers, avoids stacked catchphrases, and keeps solemn quotations free from jokes. The plugin does not create an unsolicited group reply by itself; existing mention and active-chat rules still decide whether the bot speaks.
