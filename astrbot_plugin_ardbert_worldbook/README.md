# Ardbert Worldbook

Topic-retrieval worldbook for the Ardbert chat persona on QQ Official and SnowLuma.

The plugin loads `worldbook.json`, matches the current user message against entry keywords, and injects only the most relevant lore summaries as temporary user content. It does not persist injected material in conversation history. Tarot requests, unsupported platforms, and non-Ardbert personas are excluded.

Worldbook entries use original technical summaries derived from the listed reference pages. Canonical dialogue and copied wiki prose are intentionally excluded. Spoiler labels keep major 3.4, 5.0, and 5.3 reveals out of unrelated replies.
